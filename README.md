# 🤖 Personal AI Assistant Chatbot

A simple **Rule Based AI Chatbot** built using **Python and Flask**.
This project provides a web-based chatbot interface where users can ask basic questions and get automated responses.

## 🚀 Features

* 🤖 Rule Based AI Responses
* 🌐 Flask Web Application
* 💬 Chat Interface
* ⌨️ Enter Key Message Support
* 🌙 Dark Mode UI
* 🗑 Clear Chat Feature
* ⏰ Message Time Display
* 🧠 Basic Chatbot Memory
* 📚 Custom Knowledge Base

## 🛠️ Technologies Used

* Python
* Flask
* HTML5
* CSS3
* JavaScript

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone your-repository-link
```

Go to project folder:

```bash
cd Personal-AI-Assistant-Chatbot
```

Install Flask:

```bash
pip install flask
```

Run the application:

```bash
python app.py
```

Open your browser:

```text
http://127.0.0.1:5000
```
