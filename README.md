# Rule-Based AI Chatbot

A simple AI chatbot built using Python.

## Features

* Greets users based on current time
* Responds to predefined questions
* Uses Python dictionaries for chatbot memory
* Case-insensitive input handling
* Exit command using "bye"

## Technologies Used

* Python
* Dictionary
* Functions
* Loops
* Conditional Statements

## Sample Questions

* Hello
* How are you?
* Who are you?
* Motivate me
* What is functions?

## Learning Outcome

This project helped me understand Python fundamentals such as dictionaries, functions, loops, and basic AI chatbot logic.
